# CyberOutlook

**UK Small Business Cyber Outlook 2027**, by Noel Bradford (The Small Business Cyber Security Guy). Interactive web edition v2.0.

- **Read online:** https://cyberoutlook.sbcsg.uk
- **Full report as a PDF:** [`assets/UK-Small-Business-Cyber-Outlook-2027.pdf`](assets/UK-Small-Business-Cyber-Outlook-2027.pdf)
- **Ten-slide summary:** [`linkedin/CyberOutlook2027_LinkedIn_Carousel.pdf`](linkedin/CyberOutlook2027_LinkedIn_Carousel.pdf)

The report's wording and figures are unchanged from v1.1. The web edition adds tools around them.

## What readers can do

| | |
|---|---|
| **Start** | Pick a path (two-minute check, five things, short version, full read) or a role (owner, office manager, IT, finance). |
| **Check** | Ten questions give a score and a list of gaps, each linked to the action that fixes it, with UK benchmarks from the government survey. |
| **Plan** | Add any action to My plan, give it an owner and a date, download calendar reminders, print it, or share it as a link. |
| **Tools** | IT provider email, supplier emails, call-back poster with code words, five-and-five map, AI tool register, MFA tracker, restore-test log, Cyber Essentials readiness, questionnaire answers, remote hire check, team briefing, meeting pack, renewal evidence pack. |
| **In an incident** | "It's happening now" turns the one-page plan into a full-screen card with tap-to-call contacts and a time-stamped log. |
| **Read** | Short version, listen aloud, search, glossary, highlights and notes, focus mode, simple mode, reading settings, dark mode. |
| **Share** | Share hub with ready-made LinkedIn posts, messages for colleagues, image cards for figures, quotes and forecasts, links to any tool, section or paragraph. |
| **Print** | Full PDF with page numbers and QR codes, a team pack, just the one-page plan, or a toolkit of everything you've made. |

Everything a reader types or ticks stays in their own browser. There are no accounts, cookies or analytics. Readers can export or delete their data from **Tools, Your data**.

## Publishing

GitHub Pages publishes the **`release`** branch to cyberoutlook.sbcsg.uk (Settings, Pages). Work happens on separate branches; `release` only moves when the owner says so. Nothing is merged into `main`.

## Making a change

1. Edit `index.html` (report text) or a file in `src/` (tools).
2. Run `python3 tools/build.py`.
3. Check: `python3 -m http.server 8080`, open http://localhost:8080, then `npm install` once and `npm run check`.
4. If the print layout changed, rebuild the PDF from a browser's print dialog (A4, background graphics on) or ask Claude to regenerate it.
5. Add a line to the version history comment at the top of `index.html`.
